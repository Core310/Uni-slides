# Reveal.js Standalone Slide Template

A standalone, CDN-powered Reveal.js 5.1.0 presentation template designed for university lectures, student defense talks, and interactive presentations.

## Features

- **Zero Build Step**: Runs directly in the browser via CDN without requiring npm, Quarto, or local servers.
- **Dark City Parallax**: Implements the signature Uni-slides dark theme with parallax background scrolling.
- **Dual-Window Speaker Notes**: Press `S` to launch the presenter view with live BroadcastChannel synchronization.
- **Scroll-Guaranteed Cards**: Long slide content scrolls smoothly with guaranteed bottom clearance so text is never cut off.

## Keyboard Controls

- `Space` / `→`: Next slide
- `←`: Previous slide
- `S`: Speaker Console (Notes)
- `F`: Fullscreen
- `O`: Slide Overview Grid
- `Esc`: Close overview / modals

## Customization

Copy `template.html` to a new filename (e.g. `my-topic.html`), update the headings, slide content, and `<aside class="notes">` narrative blocks.
